# 神秘小舖 - 鄭筱融生日限定版 🎂 (專案狀態紀錄)

## 📌 專案概述
本專案為一個帶有 90 年代復古、微詭異風格的網頁解謎遊戲，目的是作為給「鄭筱融」的特別生日禮物。
網站利用 Vanilla JavaScript 搭配 `localStorage` 來記錄遊戲進度，確保玩家在解鎖最終禮物前，必須完成特定的互動挑戰。

## 📁 檔案結構與核心功能
專案放置於 `mysterious_shop` 資料夾，包含以下三個核心檔案：

1. **`index.html` (主架構)**
   - **RWD 響應式佈局**：支援手機與桌機瀏覽。
   - **商品區**：展示三樣商品（隱眼、本本、神秘禮物）。
   - **密碼區 (`#blurry-zone`)**：右下角的模糊密碼區，需要驗證成功後才能看清。
   - **互動 Modal**：包含「身分驗證」、「黑歷史相簿」與「最終驚喜頁面」。
   - **已客製化進度**：文案已更新為專屬祝福，商品預設圖已改為 `gift1.png`、`gift2.png`、`gift3.png`。

2. **`style.css` (視覺樣式)**
   - **復古風格**：深色背景、霓虹綠/粉色調、復古十字鼠標、跑馬燈效果。
   - **特效**：
     - `filter: blur()` 實作密碼區模糊特效。
     - Hover 動畫與光暈效果。
     - RWD 網格系統 (`grid-template-columns`) 適配手機版。

3. **`script.js` (互動邏輯)**
   - **狀態管理 (`game.state`)**：透過 `localStorage.getItem('jason_socks_collected')` 判斷玩家是否已拿到白襪，防止進度重置。
   - **通關邏輯**：
     - **關卡一**：找出真正的陷阱妹 ➔ 解除右下角密碼模糊 (`6767`)。
     - **關卡二**：輸入密碼 `6767` ➔ 打開黑歷史相簿 ➔ 點擊拾取「Jason 的 nike 白襪」。
     - **關卡三**：判斷持有白襪 ➔ 觸發全螢幕生日驚喜（含彩帶特效與最終祝福）。
